# 디맨드 서비스 개요

> 디맨드: 생산·기능직 대상 B2C HR테크 플랫폼

## 서비스 영역

| 영역 | 설명 | 주요 기능 |
|------|------|-----------|
| **스펙리포트** | 이력서/스펙 분석 리포트 | AI 기반 이력서 분석, 경쟁률/합격률 통계 |
| **멘토링** | 1:1 현직자 멘토링 매칭 | 멘토 연결, 피드백, 커리어 상담 |
| **멤버십** | 구독형 프리미엄 혜택 | AI 자소서(PC), 멘토 피드백(앱), 가이드북 열랅 |
| **공고** | 잡코리아 연동 채용 공고 | 맞춤 공고 추천, 바로지원, 지원현황 관리 |
| **AI자소서** | AI 기반 자기소개서 작성 | 스펙 기반 자소서 자동 생성 |
| **커뮤니티** | 구직자 커뮤니티 | Q&A, 취업 후기, 정보 공유 |
| **스펙랩** | 스펙 관리/분석 도구 | 이력서 작성, 스펙 입력, 분석 결과 확인 |

## 사용자 타입

| 타입 | 설명 |
|------|------|
| 일반 구직자 | 스펙리포트, 멘토링, 공고 지원 |
| 멤버십 구독자 | AI자소서, 멘토 피드백, 가이드북 등 프리미엄 혜택 |
| 기업 회원 | 공고 등록, 지원자 관리 (gocho_business) |

## 주요 플로우

1. **스펙리포트 플로우**: 스펙 입력 → AI 분석 → 리포트 열랅 → 경쟁률/합격률 확인
2. **멘토링 플로우**: 멘토 검색 → 결제 → 매칭 → 1:1 상담
3. **공고 지원 플로우**: 공고 검색 → 바로지원 → 지원현황 확인

## CS 주요 문의 유형

| 유형 | 설명 | 처리 부서 |
|------|------|-----------|
| 버그/오류 | 기능 오류, 화면 깨짐, 결제 오류 | 개발팀 (cs-bug-handler) |
| 환불 | 스펙리포트, 멘토링, 멤버십 환불 요청 | CS팀 (cs-refund-check) |
| 계정 | 이메일 변경, 인증 해제, 탈퇴 | CS팀 (cs-account-manager) |
| 데이터 | 기업명 추가, 자격증 수정, 정보 정정 | CS팀 (cs-data-curator) |
| 멘토링 | 멘토 미연락, 연결 불발, 중재 | CS팀 (cs-mentoring-mediator) |
| FAQ | 가이드북, 멤버십 혜택, 기능 문의 | CS팀 직접 처리 |
