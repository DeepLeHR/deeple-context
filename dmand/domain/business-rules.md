# 디맨드 비즈니스 규칙

## 스펙리포트

- 미열람 상태에서만 환불 가능
- 1회 이상 열림 시 환불 불가
- 결제 후 서비스 오류로 열림 자체가 불가했던 경우 → 예외 환불 가능

## 멘토링

- 멘토 미연락 3일 이상 → 환불 가능 (단, 먼저 멘토 연락 재시도 필요)
- 멘토와 연결 불발 확정 → 환불 가능
- 멘토와 이미 연락 취해진 경우 (진행 중) → 환불 불가
- 구매 후 1~2일 이내 → 중재 시도 후 판정 (보류)

## 멤버십

- 케이스별 환불 정책 적용 (낶부 정책 확인 필요)
- 등급·가격·혜택 상세는 [../product/membership.md](../product/membership.md) 참조

## 계정

- 이메일 변경: 본인 인증 후 가능
- 소셜 인증 해제: 최소 1개 인증 수단 유지 필요
- 탈퇴: 미결제 내역 확인 후 처리

## 데이터

- 기업명 추가: 공식 명칭 기준, 유사명 구분
- 자격증 수정: 공식 발급 기관 기준
- 정보 정정: 증빙 자료 확인 후 반영
