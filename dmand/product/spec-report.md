# 스펙리포트 (AI 리포트)

채용공고 1건당 AI 분석 + 합격자 통계 + 가이드북 패키지. 2025년 11월 출시.

## 운영 모델

단위는 채용공고 1건 (예: "SK하이닉스 25년 10월 채용"). 디맨드 내 지원자를 트래킹해 스펙 통계를 생성한다. 자체 트래픽이 곧 데이터 자산이 되는 구조로, 별도 데이터 수집 비용 없음.

## 가격

9,900원/건. IR Deck(2026.01) 표기 7,900원은 구가.

## 리포트 구성

- AI 강점·보완점 요약
- 자격증·학점·경험 보강 추천
- 합격자 나이·학력·자격증·학점 분포 (히스토그램)
- 합격자 통계 vs 본인 위치 비교
- 가이드북: 직무별 추천 자격증·학습 경로

## 데이터 자산 의의

스펙리포트는 자기증식 구조를 가진다:

1. 채용공고 노출 (B2B 광고 매출 발생)
2. 지원자가 디맨드에서 지원·자소서 작성
3. 지원자 데이터를 통계로 가공
4. 다음 지원자에게 9,900원에 판매
5. 트래픽 증가 → 데이터 풍부 → 단가 인상 여지
