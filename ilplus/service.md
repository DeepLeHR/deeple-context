# 일더하기 서비스 개요

> 일더하기: 재취업·경력 전환·새 자격증을 준비하는 모든 분을 위한 B2C 커리어 플랫폼

> ⚠️ **프로젝트명 참고**: 백엔드 패키지 및 레포지토리 내부에서는 `newcareer`라는 이름을 사용합니다.  
> 신규 문서 작성 시 백엔드 코드 기준으로는 `newcareer`, 서비스/브랜드 기준으로는 `일더하기`를 사용하세요.

## 서비스 영역

| 영역           | 설명                               | 주요 기능                                                        |
| -------------- | ---------------------------------- | ---------------------------------------------------------------- |
| **커리어진단** | 1분 물류 진단 및 맞춤 자격증 추천  | 진단 문항 응답, 적합 자격증 TOP 3 추천, 대안 목록 제공           |
| **교육·강의**  | 물류 자격증 기초 강의 및 학습 관리 | 강의 목록/상세 조회, 수강신청, 강의 진도율 관리, 퀴즈/평가       |
| **일자리매칭** | 고용24 연동 위치 기반 채용 공고    | 위치 기반 공고 검색, 상세 조회, 조건 필터링(지역/직종/학력/경력) |
| **취업상담**   | 전화 및 온라인 취업 컨설팅         | 상담 신청, 예약 관리, 상담 이력                                  |
| **이력서**     | 구직용 이력서 작성 및 관리         | 이력서 등록/수정, 내역 조회                                      |
| **자격증**     | 자격증 정보 및 취득 관리           | 자격증 목록 조회, 내 자격증 관리                                 |
| **사전알림**   | 오픈 예정 서비스 및 공고 알림      | 관심 공고/강의 사전 알림 신청                                    |

## 사용자 타입

| 타입            | 설명                                                     |
| --------------- | -------------------------------------------------------- |
| 게스트 (비회원) | 커리어진단 체험, 공고 둘러보기, 강의 목록 조회           |
| 일반 회원       | 진단, 강의 수강신청·학습, 일자리 검색·상담, 이력서 관리  |
| 수강생          | 수강 중인 강의 학습, 진도율 추적, 퀴즈 응시              |
| 관리자          | 공고/강의/회원 관리, 상담 배정, 통계 조회 (admin 페이지) |

## 주요 플로우

1. **진단 플로우**: 1분 진단 응답 → 자격증 추천 결과 확인 → 맞춤 교육/강의 연계
2. **교육 플로우**: 자격증/강의 탐색 → 수강신청 → 강의 학습 → 진도율 업데이트 → 퀴즈/평가
3. **일자리 매칭 플로우**: 위치/조건 검색 → 공고 상세 확인 → 상담 신청 또는 지원
4. **상담 플로우**: 상담 신청 → 예약 확정 → 전화/온라인 상담 진행 → 후속 조치

## CS 주요 문의 유형

| 유형        | 설명                                            | 처리 부서                 |
| ----------- | ----------------------------------------------- | ------------------------- |
| 버그/오류   | 기능 오류, 화면 깨짐, 결제 오류, 진도율 미반영  | 개발팀 (cs-bug-handler)   |
| 교육/강의   | 수강신청 불가, 강의 재생 오류, 자격증 정보 문의 | CS팀 직접 처리            |
| 일자리/공고 | 공고 내용 문의, 지원 방법, 위치 검색 오류       | CS팀 직접 처리            |
| 이력서      | 작성/저장 오류, 이력서 노출 문의                | CS팀 직접 처리            |
| 상담        | 상담 예약 변경, 연결 불발, 상담사 배정 문의     | CS팀 직접 처리            |
| 계정        | 이메일 변경, 인증 해제, 탈퇴, 비밀번호 재설정   | CS팀 (cs-account-manager) |
| 데이터      | 기업명 추가, 자격증 정보 정정, 공고 정보 수정   | CS팀 (cs-data-curator)    |
| FAQ         | 진단 결과 해석, 멤버십 혜택, 기능 이용 방법     | CS팀 직접 처리            |
