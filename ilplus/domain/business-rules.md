# 일더하기 비즈니스 규칙

## 커리어진단

- 무료 서비스
- 비회원 응답 가능, 결과 저장 및 재진단을 위해 회원가입 유도
- 진단 완료 시 적합 자격증 TOP 3 + 대안 목록 제공

## 자격증 주문/결제

- **주문 조건**: 해당 자격증의 모든 강의 수강 완료 후 주문 가능
- **결제 금액**: 자격증 가격 + 배송비(3,000원)
- **주문 상태 흐름**: 결제대기(PAYMENT_PENDING) → 결제완료(PAID) → 배송중(SHIPPED) → 배송완료(DELIVERED)
- 배송 완료(DELIVERED)된 주문은 취소/환불 불가
- 결제 대기(PAYMENT_PENDING) 상태에서만 TossPayments 승인 가능
- 이미 결제 완료(DONE)된 건은 중복 승인 불가
- 결제 금액 불일치 시 승인 거부

## 교육·강의

- 무료 강의 (수강신청制)
- 수강신청 후 학습 시작, 강의 단위로 진도율 관리
- 모든 강의 수강 완료 시 해당 자격증 주문 자격 부여
- 진도율은 회원별 강의 단위로 저장 및 업데이트

## 일자리매칭

- 무료 서비스 (고용24 연동)
- 위치정보법 §16 의무 — 위치 기반 검색 시 이용 사실 자동 기록
- 회원의 경우 이용 시점 전화번호를 스냅샷해 사후 변경/탈퇴와 무관하게 §16 응대

## 취업상담

- 무료 상담 (전화/온라인)
- 상담 예약 후 미연결 시 재예약 또는 상담사 재배정 안내

## 계정

- 이메일 변경: 본인 인증 후 가능
- 소셜 인증 해제: 최소 1개 인증 수단 유지 필요
- 탈퇴: 미결제 내역(결제 대기 중인 주문) 확인 후 처리

## 데이터

- 기업명 추가: 공식 명칭 기준, 유사명 구분
- 자격증 수정: 공식 발급 기관 기준
- 정보 정정: 증빙 자료 확인 후 반영
