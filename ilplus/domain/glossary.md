# 일더하기 도메인 용어집

| 용어         | 영문                  | 설명                                                      |
| ------------ | --------------------- | --------------------------------------------------------- |
| 커리어진단   | Career Diagnosis      | 1분 무료 진단, 적성·관심사 분석 후 맞춤 자격증 TOP 3 추천 |
| 페르소나     | Persona               | 진단 결과에 따른 사용자 유형(예: 도전형, 안정형 등)       |
| 자격증       | Certification         | 국가/민간 자격증 정보 및 취득 지원 프로그램               |
| 강의         | Course                | 자격증 취득을 위한 무료 온라인 차시 묶음(과정)            |
| 차시         | Lecture               | 강의를 구성하는 세부 단위                                 |
| 수강신청     | Enrollment            | 코스(강의) 수강 등록                                      |
| 진도율       | Progress Rate         | 회원별 강의 단위 학습 진행 비율                           |
| 시험         | Quiz                  | 강의 수강 후 응시하는 학습 평가 및 자격증 주문 자격 확인  |
| 자격증 주문  | Certification Order   | 자격증 신청 키트/교재 등의 유료 주문                      |
| 배송비       | Shipping Fee          | 자격증 주문 시 추가되는 배송 비용(3,000원)                |
| 일자리       | Job                   | 고용24 연동 채용 공고                                     |
| 위치기반검색 | Location-based Search | 사용자 위·경도 기반 근거리 일자리 검색                    |
| 상담         | Consultation          | 취업 관련 전화/온라인 상담                                |
| 이력서       | Resume                | 구직용 이력서(경력, 자격증, 희망근무지 등)                |
| 사전알림     | Pre-notification      | 오픈 예정 서비스 또는 관심 공고의 사전 알림 신청          |
| 장학금       | Scholarship           | 교육 과정 수강 지원금 또는 수강 혜택                      |
| 회원         | Member                | 일더하기 서비스 가입자                                    |
| 고용24       | Work24                | 정부 구직활동 확인서 발급 사이트(www.work24.go.kr)        |
